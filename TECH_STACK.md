# TECH STACK

_Tech stack used for development of **Proactive** as a Web Application_

## Frontend

**React** has been chosen for the app frontend for its flexibility, reliability, and stability. It is also good for Rapid Prototyping and development of MVPs when paired with a backend framework like FastAPI.

## Backend

**FastAPI** has been chosen for the app backend for Rapid Prototyping and simplicity.

## Authentication

**Google OAuth 2.0** has been chosen for app authentication and permissions to access Google Calendar.
